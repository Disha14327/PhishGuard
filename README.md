🛡️ PhishGuard

An Educational Phishing Detection and Awareness Platform

Team Name: CyberAegis

📌 About the Project

PhishGuard is a web-based cybersecurity awareness platform designed to help users identify potentially suspicious URLs and phishing messages. It provides a risk score, explains suspicious indicators, and offers safety recommendations.

✨ Key Features

- URL Scanner: Checks URLs for suspicious patterns.
- Message Scanner: Analyses messages for possible phishing indicators.
- Risk Assessment: Displays a risk score based on detected patterns.
- Warning Explanations: Explains why a URL or message may be suspicious.
- Safety Tips: Provides useful cybersecurity awareness recommendations.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
